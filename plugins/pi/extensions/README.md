# Neutral Pi Extension Adapters

Thin Pi adapters for neutral Sandpiper capabilities.

- `capabilities.ts` registers neutral background-process capabilities.
- `shell-relay.ts` exposes the shared terminal relay extension.
- `web-fetch.ts` exposes the web fetch tool extension.
- `autotoon.ts` exposes the AutoTOON Pi lifecycle adapter.

Do not add Sandpiper identity, migration, startup prompt, diagnostics, or update behavior here.
