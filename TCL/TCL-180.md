# Task move permits a task to become its own parent

Confirmed against the built standalone CLI during TCL-174. Create APP-1 normally, then task move APP-1 --kind SUBTASK --parent APP-1. Exit is 0. The file becomes APP/APP-1/APP-1.md with parent APP-1. Structured task show returns the same task twice (primary plus its own child). Root: validateMoveTarget/validateParentIsTopLevel verify current parent existence/kind but not self-parenting. Reject self-parenting before counter/file/history writes and test the original tree remains unchanged. Preserve valid demotion behavior that reparents existing children.
