# Title updates can replace a YAML comment instead of the body heading

Reproduced during the full Trail documentation pass. This is a separate runtime defect, not a docs change or a blocker for TCL-159.

Location: src/core/mutate.ts, applyTitleUpdate(). The whole-document replace(/^# .+$/m, ...) matches a YAML frontmatter comment before the Markdown body heading.

Reproduction: initialize a scratch store; create APP-1 with title Original title; insert # Frontmatter comment immediately after the opening --- line; run task update APP-1 -t "Updated title".

Expected: the title field and body heading change, while the comment remains untouched.

Actual: the title field and comment become Updated title, while the body heading remains # Original title.

Verified through the built CLI in /tmp/trail-docs-full-pass.mjs; latest scratch /var/folders/zj/49vt4cds6l15fs_1frdvz89r0000gn/T/trail-full-docs.hfiytD/title-comment. docs/task-format.md now states this implemented limitation rather than claiming unconditional body/frontmatter preservation. No runtime fix attempted.
