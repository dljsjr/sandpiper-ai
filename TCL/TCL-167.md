# Title updates can replace a YAML comment instead of the body heading

Reproduced during the full Trail documentation pass. This is a separate runtime defect, not a docs change or a blocker for TCL-159.

Location: src/core/mutate.ts, applyTitleUpdate(). The whole-document replace(/^# .+$/m, ...) matches a YAML frontmatter comment before the Markdown body heading.

Reproduction: initialize a scratch store; create APP-1 with title Original title; insert # Frontmatter comment immediately after the opening --- line; run task update APP-1 -t "Updated title".

Expected: the title field and body heading change, while the comment remains untouched.

Actual: the title field and comment become Updated title, while the body heading remains # Original title.

Verified through the built CLI in /tmp/trail-docs-full-pass.mjs; latest scratch /var/folders/zj/49vt4cds6l15fs_1frdvz89r0000gn/T/trail-full-docs.hfiytD/title-comment. docs/task-format.md now states this implemented limitation rather than claiming unconditional body/frontmatter preservation. No runtime fix attempted.

## Fix and verification

Committed in standalone Trail as rouznttp / 6c79ec6e. The failing regression proved that the old whole-document heading replacement overwrote the YAML comment and retained the original body heading. Heading replacement now searches only after the frontmatter content, using the existing parser-owned frontmatter extractor. Tests cover LF, CRLF, preserving later headings/body text, and a body without a heading. No unrelated writer or description changes.

Baseline: 586 tests / 37 files, TypeScript and build pass. After fix: 589 tests / 37 files, TypeScript and build pass. Actual built CLI reproduction before and after: /tmp/trail-tcl167-cli.mjs; before scratch /var/folders/zj/49vt4cds6l15fs_1frdvz89r0000gn/T/trail-tcl167-before-hXg0dQ; after scratch /var/folders/zj/49vt4cds6l15fs_1frdvz89r0000gn/T/trail-tcl167-after-XQ6xKA. The fixed executable preserves the comment/description and changes both title field and body heading. Updated docs/task-format.md to remove the old limitation. Full suite log /tmp/trail-tcl167-tests.log. No live boards or Sandpiper source changed.
