# Slice 2: neutral defaults, drop sandpiper paths and aliases

Flip the defaults to neutral names now that they live in one place.

- Tasks tree default becomes `.trail/tasks`.
- Config file becomes `.trail/config.json`. Single candidate for now — the `.trail.json` / `trail.json` alternates are deferred.
- Drop reading the `tasks` key from `.sandpiper/settings.json` entirely.
- Rename the cosmetic temp-dir prefixes to `trail-`.
- No compatibility, no aliases, no fallback to the old paths. Trail must not know the old format exists; that knowledge belongs to a migration tool in sandpiper-ai.
- Drop the `sandpiper-tasks` invocation alias in `src/index.ts` (the argv[0] sniff that switches the help banner).

Gitignore care: `storage-cmd.ts` currently ignores `.sandpiper/tasks/` — the SUBDIRECTORY, not the parent. It must become `.trail/tasks/` and must NOT be "simplified" to `.trail/`, or Trail would gitignore its own config file.

Verification: `tsc --noEmit` clean, full suite green. Test fixtures will need updating here — that is expected and legitimate this time. Every test edit must be justified by the stated behavior change. An edit that exists to turn red green without a behavior reason is a defect, not a fixture update.

## Added 2026-08-12 (Roux, after TCL-147 review)

TCL-147 left **14 `.sandpiper` references in doc comments and docstrings**. That was correct for a behavior-preserving slice — comments are not behavior — but they become actively *wrong* here, describing `.sandpiper` while the code resolves `.trail`. They are this slice's to fix:

`storage-cmd.ts:18`, `consistency-guards.ts:6`, `auto-commit.ts:20`, `storage-config.ts:55-56`, `mutate.ts:398,406`, `archive.ts:49`, `search.ts:59`, `history.ts:10,12`, `migrate.ts:4,33,36`.

One of them is not a rename: `consistency-guards.ts:6` points at `.sandpiper/docs/specs/trail-consistency-checks-plan.md`, a path in **sandpiper-ai**, not Trail. After extraction that reference dangles. Either repoint it at wherever the doc lands or drop it — do not mechanically rewrite it to `.trail/docs/...`, which would invent a file that does not exist.

Note that the help text (`index.ts`) and the two error strings (`helpers.ts`, `migrate.ts`) already derive from `TASKS_DIR_SEGMENTS` and `STANDALONE_CONFIG_FILENAME` after TCL-147, so they flip for free when the constants change. Do not re-hardcode them.
