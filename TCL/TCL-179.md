# Task creation accepts invalid project keys and produces unqueryable files

Confirmed against the built standalone CLI during TCL-174. In a fresh temporary no-VCS store, task create -p X -t 'Invisible task' exits 0 and creates X/X-1.md. task list -f json returns []. Root: src/core/mutate.ts:98-113 does not enforce PROJECT_KEY_RE although createProject does and the task walker only accepts keys with at least two uppercase letters. Reuse project-key parsing before filesystem changes in create and move. Also cover traversal-shaped input in isolated temporary stores and verify no writes outside the configured task directory. No broad path-hardening redesign is required.
