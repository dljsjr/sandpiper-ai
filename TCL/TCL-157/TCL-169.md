Scope: produce a complete v2 configuration and a create/already-adopted/refused result without writing files or running VCS commands. Preserve effective legacy VCS behavior and the existing task-directory location. Disabled VCS emits only enabled: false. With no legacy source, defaults apply only after the same workspace-safety checks.

Completion criteria:
- Existing relative and absolute directories pass the current Trail path/physical-location rules. Missing directories and unsafe or inconsistent checkout/configuration combinations refuse before changes.
- Inspect all three Trail configuration candidates. Equivalent valid configuration is a no-op. Malformed, conflicting, or ambiguous input refuses rather than falling back to fresh defaults. Valid partial legacy configuration still uses characterized legacy defaults.
