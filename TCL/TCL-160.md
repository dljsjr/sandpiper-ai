# Move the TCL board into the Trail repo

Trail is its own repo, but its board lives in sandpiper-ai. TCL-146 gave a good reason at the time:

> Trail's own board would sit at `.sandpiper/tasks` — the exact path this work renames — so tracking the work in the tool being modified would break the board mid-cutover.

**That reason has expired.** The cutover shipped, `.trail` is the default, and the path is no longer in flux.

The other stated objection — "Trail has no cross-repo move" — is still true of the tooling but no longer a blocker in practice. The hand method was worked end to end on 2026-08-12 migrating AGENT-279..283 into PIEXT-36..40 in the yaams repo: recreate on the target board preserving bodies, priorities, kinds, assignees and dependency edges, then close the originals WONTFIX with pointers standing in for tombstones. Inbound references must be checked by hand, since nothing rewrites them.

**Blocked on TCL-156.** A TCL board in `~/git/trail` would be managed by standalone Trail at toon 4.1.1, and the bundled tasks skill script — the binary actually used to read boards on this machine — is 2.3.0 and cannot parse a 4.x index. Moving the board before that rollout lands would wedge it on arrival.

Scope note: roughly 87 TCL tickets, most COMPLETE. Consider whether closed history moves, gets archived in place, or stays behind — a hand migration of 87 items is a different proposition from the 5 that were moved for PIEXT.

Deferred out of TCL-146; filed 2026-08-12 when that ticket reached review.
