# Fix slash shortcut stealing focus from Glimpse board form fields

The Glimpse task board uses / as a global focus-search shortcut, but it currently fires while typing in task creation fields. That makes / impossible to type or paste reliably in titles/descriptions. Scope the shortcut so it only fires when focus is not in an editable input, textarea, select, or contenteditable element.
