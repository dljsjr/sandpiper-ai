## How to read the tables

| Term in `Proposed` | Meaning                                                                    |
| ------------------ | -------------------------------------------------------------------------- |
| keep               | A live consumer was found. No change proposed                              |
| remove             | No consumer was found. Deleting it changes no behavior                     |
| simplify           | The surface stays, with fewer files, entries, or branches                  |
| archive            | Move the document to `.sandpiper/archive/`                                 |
| correct            | The document states something false. Fix the statement                     |
| decide             | A real tradeoff. The row states the options                                |
| tracked            | An existing task already owns the decision. This inventory does not reopen |
| replace            | Swap the surface for a smaller or built-in equivalent                      |

The `Checked` column records how many independent checks support the row. `2` means a read-only audit agent reported it and the coordinator repeated the search. `1` means audit-agent evidence only.

In Section 2, `split` means the row covers two surfaces that need separate decisions.

Sections 4 to 7 have no `Checked` column. The coordinator re-ran the check behind every row in them on 2026-11-10. A row that rests on an audit agent alone says `agent evidence`.

An empty `Decision` cell means the decision is pending.
