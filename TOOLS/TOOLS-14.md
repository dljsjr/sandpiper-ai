# Fix generated Dash CLI under ESM package type

The Dash skill helper CLI generated by mcporter with --runtime node --bundle is CommonJS, but the generated executable is extensionless. After dist/package.json started declaring type: module, Node treats the extensionless script as ESM and fails with ReferenceError: require is not defined in ES module scope. Fix generation/assembly so the distributed Dash helper works from all Sandpiper surfaces without introducing hidden package-level CommonJS islands.
